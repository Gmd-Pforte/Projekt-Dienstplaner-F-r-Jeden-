# Dienstplaner für Jeden

Erste Android-Version des freundlichen, regelbasierten Dienstplaners.

## Version 0.1.0

Enthalten:
- freundliches Dashboard mit Seitenmenü
- Mitarbeiter anlegen mit individuellen Regeln
- Früh-, Spät- und Nachtschichten mit Besetzung und Pausen
- Urlaub und Freiwünsche
- regelbasierter automatischer Wochenplaner
- Konflikthinweise bei unbesetzten Diensten
- Auswertung und Einstellungen für Berufsgruppe/Bundesland
- Hell-/Dark-Mode
- Homescreen-Widget „Nächster Dienst“
- lokale Offline-Speicherung als Basis für spätere Team-Synchronisation

Die App ist bewusst Local-First aufgebaut. Eine spätere Vernetzung über ein Backend kann ergänzt werden, ohne die komplette App neu zu strukturieren.
